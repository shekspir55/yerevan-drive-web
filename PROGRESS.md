Goal: browser port of the 2005 game, built **from the original code and data** (decompiled with Ghidra, original files loaded at runtime), as identical as possible: Armenian menu, splash, reflections, physics. Multiplayer later.
Working mode: single thread, no subagents (decision 2026-10-25). Update this file after every step.

## How to run
- Web port: `./start.sh` (node server.js, includes the multiplayer relay) → http://localhost:8099/ (serves `web/`, game data via the `web/game` symlink).
- Original game (reference): `./run-original.sh` – **do not use casually**: it re-modes the monitors (see Risks).
- Test URLs (query params): `?auto=1` skip menu, `&demo=1` self-drive, `&warp=N` simulate N s first, `&mode=gonka&track=0&laps=2&opps=3&traffic=0` race, `&phys=arcade` old physics, `&dbg=1` race log.
