Yerevan Drive - version 1.1

---English---
Copy your favourite MP3s to the directory \MP3\ to listen them during the game

CONTROLS:
Accelerate - UP
Brake - DOWN
Steer left - LEFT
Steer right - RIGHT
Handbrake - SPACE
Shift up - A
Shift down - Z
Camera view - C
Look behind - B
Next song - N
Horn - H
Alert turn on - M (works only in "Gogh - Milica" network game)

MAP CONTROLS:
Zoom in - "+" (plus)
Zoom out - "-" (minus)

---Russian---
